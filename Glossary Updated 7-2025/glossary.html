HTML and CSS Glossary

Chapter 1

Protocols
The rules that describe how clients and servers communicate with each other over a network.
Hypertext Transfer Protocol
A set of rules for exchanging files such as text, graphic, sound, etc. on the Web.
Internet Protocol - IP
A set of rules that controls how data are sent between computers on the Internet.
Standard Generalized Markup Language
Created by Tim Berner-Lee, this is a standard format for embedding descriptive markup within a document and for describing the structure of a document.
Hypertext Markup Language
A set of markup symbols or codes placed in a file that is intended for display on a web page.

Chapter 2

Wireframe
Indicates how the structure of a web page could be configured with the header, nav, main, div, and footer elements.
Site Map
This represents the structure or organization of pages in a website in a visual manner.
DIV element
Configures a generic structural area or "division" on a web page as a block display with empty space above and below. This is used when you need to format an area of a web page that may contain other block display elements such as headings, paragraphs, unordered lists, and other div elements.
Description List
This is used to organize terms and their descriptions.
Paragraph element
Groups sentences and sections of text together.

Chapter 3

Hierarchical Organization
This is characterized by a clearly defined home page with links to major site sections.
POUR
An acronym meaning "Perceivable, Operable, Understandable, and Robust." The content must be perceivable, the internet components must be Operable, the content and controls must be Understandable, and the content must be Robust enough to work with current and future user agents.
Hero
Text content on a white background for maximum contrast while engaging the visitor with a large graphic.
Single Page Website
A website that contains one very long page - a single HTML file - with a clearly defined navigation area, usually at the top of the page.
Breadcrumb Trail
Indicates the path of web pages a visitor has viewed during the current session.

Chapter 4

CSS Style Rule Declaration
Indicates the CSS property you are setting (such as color) and the value you are assigning to the property.
Style element
Begins the area with embedded style rules. It is applied to the entire document and is located at the head section of a web page.
Link element
Associates an external style sheet with a web page. It is placed in the head section of the web page.
Class selector
Applies a CSS declaration to one or more areas on a web page. When setting a style for a class, configure the class name as the selector, and place a dot or period in front of the class name in the style sheet.
ID selector
Identifies and apply a CSS rule uniquely to a single area on a web page.

Chapter 5

Image optimization
The process of creating with the lowest file size that still renders a good quality image.
Img element
Configures graphics on a web page, such as photos, banners, etc.
Font-family property
Configures font typeface.
List-style-type
Configures the style of the list marker.
Area element
Defines the coordinates or edges of the clickable area; a void tag that uses href, alt, title, shape, and coords attributes.

Chapter 6

Width property
Configures the width of an element's content in the browser viewport with either a numeric value unit, a percentage of the parent element, or viewport width value, which is 50% of the viewport height.
Height property
Configures the height of an element's content in the browser viewport with either a numeric value unit, a percentage of the parent element, or viewport height value, which is 50% of the viewport height.
Margin property
Configures margins on all sides of an element. Determines the empty space between the element and any adjacent elements, uses numeric value.
Border property
Configures the border, or boundary, around the element.
Linear gradient
Smooth blending of color in a single location.

Chapter 7

Float property
Renders the elements using normal flow and then shifts them to either the right or left as far as possible within their container (usually either the browser viewport or a div element.
Overflow property
Often used to clear a float, although its intended purpose is to configure how content should display if it's too large for the area allocated.
Box-sizing property
Causes the browser calculation of the width or height to include the content's actual width or height in addition to my width, height of padding and border.
Text-decoration property
Modifies the display of text in the browser and is most often used to eliminate the underline from the hyperlinks.
Display property
Configures the way that browsers render elements.

Chapter 8

CSS Flexible Box Layout
Also known as flexbox, it provides a flexible layout - elements contained within a flex container can be configured in one dimension in a flexible manner with flexible sizing.
Justify-content property
Configures how the browser should display extra space along the main axis in the flex container.
Align-items property
Configures the way the browser displays extra space along the crossaxis of the container.
Gap, row-gap, column-gap
Configures space between rows between columns using a numeric length or percentage.
CSS Grid Layout
Configures a 2D grid based layout.

Chapter 10

Form
An HTML element that contains and organizes objects.
Input element
Configures a wide variety of different form controls, including text boxes, submit buttons, etc.
Boolean attributes
Not coded with a value, indicates different types of browser behavior.
Check box
A form control that allows the user to select one or more options.
Radio box
A form control that allows the user to select only one option.
